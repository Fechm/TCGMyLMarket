# TCG MyL Market

Compara los singles y el producto sellado vigente de Mitos y Leyendas de La Ira con el mercado chileno, y lista lo que otras tiendas venden y La Ira no.

- `npm test` corre las pruebas.
- `npm run actualizar` lee las tiendas y regenera `public/data/` e `historial/` (toma 10–15 minutos).
- El sitio es `public/`, servido tal cual por Cloudflare Pages.
- Proyecto independiente, sin afiliación con Mitos y Leyendas.
