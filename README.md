# TCG MyL Market

Compara los singles de Mitos y Leyendas de La Ira con el mercado chileno y lista las cartas que otras tiendas venden y La Ira no.

- `npm test` corre las pruebas.
- `npm run actualizar` lee las tiendas y regenera `public/data/` e `historial/` (toma 10–15 minutos).
- El sitio es `public/`, servido tal cual por Cloudflare Pages.
- Diseño: `docs/superpowers/specs/2026-10-21-tcg-myl-market-design.md`.
